# Introduction

A free, public JSON API for the PHP community.

<aside>
    <strong>Base URL</strong>: <code>https://www.elephpant.me</code>
</aside>

Everything here is public, read-only and needs no API key. Herds marked private by their
owner are excluded from every endpoint.

The machine-readable spec lives at [/openapi.yaml](/openapi.yaml). Country codes are
ISO 3166-1 alpha-3 (`DNK`, `GBR`, `BRA`).

Be kind to the herd: cache what you fetch rather than re-reading the whole catalogue.
